# シンプル Google カレンダー埋め込み

自分の Google カレンダーを、Notion や社内のページに時間割として出す道具です。
リンクを作るページでリンクか埋め込みコードを作り、貼るだけで使えます。どこにも登録はされません。

- リンクを作るページ：https://asiro-marketing.github.io/simple-gcal-embed/
- 作る人も見る人も、会社の Google アカウント（@asiro.co.jp）でログインします

## 使い方（3分）

1. リンクを作るページを開き、「Google でログイン」を押す
   - 初めてのときは、Google から「カレンダーの予定を見る」「カレンダーの一覧を見る」「この道具専用の保存場所を使う」「メールアドレス・名前を見る」の許可を求められます。予定を作る・変える・消す許可は求めません
2. 出すカレンダーを一覧から選ぶ。「＋ カレンダーを足す」で重ねて出せる。色はカレンダーごとに選べ、「予定の色」に印を付けると Google カレンダーで予定に付けた色のまま出る
3. 表示のしかたを選ぶ（週・日・月・予定リスト、週の始まり、表示する時間帯、終日の予定、土日、予定名を隠す、明るい／暗い色、背景の透明、上の切り替えボタン）
4. 「このリンクを保存」を押す。保存したリンクは「作ったリンク」に並び、あとから開いて直せる（何本でも作れる。別のパソコンでも同じ一覧が出る）
5. リンクをコピーし、Notion のページで「/埋め込み」と入力して貼る →「リンクを埋め込む」を押す → 枠の右下の角を下へドラッグして高さを合わせる

Notion 以外（Google サイト・WordPress など）に貼るときは、「埋め込みコード」をコピーし、そのサイトの「埋め込み」や「HTML を追加」の欄に貼ります。Slack や Chatwork のように枠を埋め込めない所には出せません。

Notion のパソコン用アプリやスマホでは、ログインの小窓が開かないことがあります。そのときは枠の中の「ブラウザで開く」を押すか、ブラウザで Notion を開いてください。

## だれに何が見えるか

- 見る人に見えるのは、その人が Google カレンダーであなたのカレンダーを開いたときと同じ中身だけです
- 社内の人に予定名まで見せているか、時間帯だけかは、Google カレンダーの「設定」→ 左の自分の名前 →「予定のアクセス権限」で確かめられます
- 予定ごとに「非公開」にした予定は、あなた自身が見ても「予定あり」とだけ出ます
- 「予定名を隠す」に印を付けると、この枠を見る全員に「予定あり」とだけ出ます。Google カレンダーの共有設定は変わりません
- リンクを社外の人に渡されても、会社のアカウントでログインできない人には何も出ません
- 予定は Google から見る人の画面へ直接届き、ほかの場所には保存されません
- 見る権限が無いカレンダーは、枠の上に「見る権限なし」と出ます（ほかのカレンダーは出ます）
- 取り消した予定、欠席と返事した予定、勤務場所（「オフィス」「自宅」の表示）は出しません

## 知っておくこと

- ログインは1時間で切れます。切れると枠に「Google でログイン」のボタンが出るので、押すとまた予定が出ます。ページを開いた人がそれぞれ自分で押します
- やめるときは、貼った埋め込みを消すだけです。Google の許可は、Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」から取り消せます

## 仕組み（管理する人向け）

- 画面のファイル（HTML と JavaScript）だけで動き、サーバーはありません。画面は GitHub Pages（このリポジトリの `docs/`）で配っています
- ログイン用の設定（OAuth クライアント）は、会社の Google Cloud のプロジェクト「Simple Google Calendar Embed」（ID：asiro-calendar-embed）にあります。管理者が1人だけにならないようにしてください
- ログインは Google Identity Services のトークン方式です。権限は `calendar.events.readonly`（予定を読むだけ）・`calendar.calendarlist.readonly`（カレンダーの一覧）・`drive.appdata`（作ったリンクの保存。ドライブのこの道具専用の見えない場所だけ）と、メールアドレス・名前です
- 作ったリンクは、各自の Google ドライブの「アプリ専用の場所」（appDataFolder）に `simple-gcal-embed-links.json` として保存します
- リンクの設定は `#` の後ろに入れます（`c=カレンダーID|色|凡例の名前` をカレンダーの数だけ、`view`・`ws`・`days`・`h`・`allday`・`hide`・`theme`・`bg`・`nav`）
- 予定は、ブラウザから Google カレンダー API を見る人のトークンで直接読みます
- 会社の Google の設定では、ログインなしで見られるページ（GAS の「全員」公開）を管理者が止めています。このため、見る人にもログインしてもらう作りにしています
- トークン方式はサーバーを持たないため、1時間でログインが切れ、自動では延長できません

### ファイル

| ファイル | 役割 |
|---|---|
| `docs/index.html` | リンクを作るページ（ログイン→表示の選択→リンク） |
| `docs/widget.html` | 埋め込む枠（週・日の時間割） |
| `docs/common.js` | ログインと Google カレンダー API の呼び出し |
| `docs/config.js` | OAuth クライアント ID |

### OAuth クライアントの作り方（最初の1回）

1. Google Cloud のコンソールでプロジェクトを選び、「Google Calendar API」を有効にする
2. 「Google Auth Platform」で、対象（ユーザーの種類）を「内部」にする。会社のアカウントだけがログインできるようになる
3. 「クライアント」で「ウェブ アプリケーション」を作り、承認済みの JavaScript 生成元に `https://asiro-marketing.github.io` と `http://localhost:8765`（手元で確かめる用）を入れる
4. できたクライアント ID を `docs/config.js` の `CLIENT_ID` に入れる

### 手元で確かめる

```
cd docs && python3 -m http.server 8765
```

- リンクを作るページ：http://localhost:8765/
- ログインせずに見た目だけ見る：http://localhost:8765/widget.html#cal=sample&name=見本&demo=1
