# カレンダーを Notion に埋め込む

自分の Google カレンダーを、Notion のページに時間割として出す道具です。
登録ページでリンクを作り、Notion に貼るだけで使えます。

- 登録ページ：https://asiro-marketing.github.io/notion-calendar-widget/
- 見る人も作る人も、会社の Google アカウント（@asiro.co.jp）でログインします

## 使い方（3分）

1. 登録ページを開き、「Google でログイン」を押す
2. 表示名・表示のしかた（週／日、土日を出すか、予定名を隠すか）を選ぶ
3. できたリンクをコピーし、Notion で「/埋め込み」と入力して貼る。枠の右下をドラッグして高さを合わせる（週の表示なら 600px くらい）

## 見える範囲

- 予定は、見る人が自分のアカウントで Google カレンダーから読みます。見える範囲は Google カレンダーの共有設定のとおりです
- 予定名が出るのは、カレンダーの持ち主が予定の詳細を社内に公開しているか、見る人に共有している場合だけです
- 「非公開」にした予定は、持ち主本人が見ても「予定あり」と出ます。埋め込んだページは他の人も開くためです
- 取り消した予定・欠席と返事した予定・勤務場所の札は出しません

## 知っておくこと

- ログインは1時間ごとにボタンを1回押す形です。Google の仕組み上、サーバーを持たない作りでは自動で延長できません
- Notion のアプリで表示されないときは、ブラウザで Notion を開いてください
- 登録の記録はどこにも残りません。やめたいときは Notion から埋め込みを消すだけです

## 仕組み（管理する人向け）

- GitHub Pages に置いた画面だけで動き、サーバーはありません
- ログインは Google Identity Services のトークン方式です。権限は `calendar.events.readonly`（予定を読むだけ）と、メールアドレス・名前です
- 予定は、ブラウザから Google カレンダー API を見る人のトークンで直接読みます。予定の中身が社外のサーバーを通ることはありません
- 会社の Google の設定では、ログインなしで見られるページ（GAS の「全員」公開）を管理者が止めています。このため、見る人にもログインしてもらう作りにしています

### ファイル

| ファイル | 役割 |
|---|---|
| `docs/index.html` | 登録ページ（ログイン→表示の選択→リンク） |
| `docs/widget.html` | Notion に埋め込む部品（週・日の時間割） |
| `docs/common.js` | ログインと Google カレンダー API の呼び出し |
| `docs/config.js` | OAuth クライアント ID |

### OAuth クライアントの作り方（最初の1回）

1. Google Cloud のコンソールでプロジェクトを選び、「Google Calendar API」を有効にする
2. 「Google Auth Platform」で、対象（ユーザーの種類）を「内部」にする。会社のアカウントだけがログインできるようになる
3. 「クライアント」で「ウェブ アプリケーション」を作り、承認済みの JavaScript 生成元に次の2つを入れる
   - `https://asiro-marketing.github.io`
   - `http://localhost:8765`（手元で確かめる用）
4. できたクライアント ID を `docs/config.js` の `CLIENT_ID` に入れて push する

### 手元で確かめる

```
cd docs && python3 -m http.server 8765
```

- 登録ページ：http://localhost:8765/
- ログインせずに見た目だけ見る：http://localhost:8765/widget.html#cal=sample&name=見本&demo=1
